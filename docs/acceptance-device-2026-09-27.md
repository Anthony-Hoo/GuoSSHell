# 真机 E2E 补充验收（2026-09-26—27）

## 结论

一台 iPad 真机上的 38 个集成测试场景通过；原生 UI 的后台恢复与横竖屏重排通过。
实体操作与远端记录确认了指针移动、双向滚轮、回车、退格和中文文本提交。
验收尚未全绿：实体修饰键组合及修饰键点击未通过，部分短场景卡顿与一次空闲回显超过门槛。
指定英文大小写序列和中文词组未匹配，不能把文本提交可用当作完整的键盘与输入法验收通过。

本轮使用已配对设备的 USB 网络通道连接独立验收容器。Wi-Fi 路径不可达，结果不代表无线链路性能。
设备标识、系统版本、签名、主机地址和原始证据保存在本机 `build/m6/`，不入库。
测试台、假模型剧本与通过标准沿用 [M6 验收定义](acceptance-m6-2026-09-26.md)。

## 实体输入核对

用户完成实体操作后，远端共记录 264 条输入、2854 字节，其中包含 255 个 SGR 鼠标事件。
鼠标按钮码为 35（无按钮移动，167 次）、0（普通左键按下或松开，60 次）、64 和 65（双向滚轮，各 14 次）。
没有出现 Option 或 Control 的点击修饰位；用户也确认 Ctrl 和其他修饰键组合没有生效。
因此修饰键问题已在实体操作中复现，不能仅归因于 XCTest 合成限制。Shift 本地选区仍未通过验收。

文本记录包含 `az09`、回车 `0d`、退格 `7f` 及一段中文 UTF-8 文本；指定的 `aZ09`、
`Ctrl+[` 对应的 Esc `1b` 与「中文测试」均未匹配。中文文本可以提交，但本轮没有逐步对应的输入法
选词、取消和提交记录，因此这些操作以及精确大小写仍需单独复验，不能据此断言 App 丢字或改写中文。

代码检查确认终端按键与鼠标点击都读取 Flutter 的 `HardwareKeyboard` 修饰键状态，
但当前证据只有远端输入与用户反馈，尚未采集 UIKit 和 Flutter 原始事件，根因未定。
后续需要在同一次实体操作中对照系统事件、Flutter 修饰键状态与远端字节。

## 性能

性能门槛使用关闭截图的 profile 轮次判断。iOS 的 `integration_test` 插件按名称保留截图原图，
带截图的长批次会把这些图像计入 App RSS，不能据此判断业务会话的内存增长。
视觉轮保留 44 张场景截图，另有协议截图和 XCUITest 附件。

视觉轮初始为横屏，无截图全套性能轮初始为竖屏；两者不是完全相同的对照条件。
横屏的无截图性能仍需复验。下表数值均来自无截图轮，卡顿门槛逐场景判断。

| 指标 | 实测 | 门槛判定 |
|---|---|---|
| 显示延迟，各窗口 p95 最大值 | 15.04 ms | 通过，≤ 50 ms |
| 显示延迟最大值 | 40.65 ms | 通过，≤ 250 ms |
| ACK 超时 | 0 | 通过 |
| agent 输入回显 | 19–69 ms | 通过，≤ 150 ms |
| 另一窗格高速输出时的 shell 回显 p95 | 18 ms | 通过，≤ 50 ms |
| 空闲 shell 回显 p95 | 218 ms；12 个样本中其余 11 个为 17–19 ms | 未通过，需扩大样本并定位异常 |
| 短场景卡顿帧比例 | 最大 4.58% | 部分场景未通过，门槛为 1% |

这些长会话的增长符合本轮门槛。多窗格洪水输出保留滚回时峰值约为 289 MB；
该结果不构成无限长运行或其他负载下无泄漏的证明。

## 视觉与限制

代表性的全屏界面、代码块、中文表格和横竖屏截图已复核。
复合 emoji 的肤色、家族与旗帜序列仍有拆分显示；网格一致性通过不代表字素簇合成正确。

本轮不覆盖 iPhone、双设备 iCloud 钥匙串同步、真实 OpenPGP / FIDO2 硬件，亦不验证真实模型服务或 GPU 负载。
长时间后台挂起、锁屏解锁及输入法选词与取消的精确交互仍需补验。

## 复测入口

先在本机配置可达的测试服务器、设备标识与签名覆盖；这些值不写入仓库。
`M6_HOST` 是设备能访问的服务器地址，`M6_PORT` / `M6_LLM_PORT` 分别是 SSH 与测试记录接口。
需要分开指定 HTTP 主机时使用 `M6_LLM_HOST`。

```bash
M6_MODE=debug ./scripts/m6.sh device protocol "$M6_UDID"
./scripts/m6.sh device performance "$M6_UDID"
./scripts/m6.sh device performance "$M6_UDID" --dart-define=M6_SCREENSHOTS=false
./scripts/m6.sh ui-device "$M6_UDID"
./scripts/m6.sh device network "$M6_UDID"
```

`ui-device` 使用 profile 构建和实际连接表单；原始字符字节测试需要英文输入法。
`M6_UI_TESTS` 可限定原生测试方法，`M6_REPORT` 可区分复测报告。
实体输入入口为 `integration_test/m6_manual_app.dart`，需以 profile 构建，并通过 `M6_HOST` / `M6_PORT`
配置同一测试台。它只接收实际输入，不合成按键。
