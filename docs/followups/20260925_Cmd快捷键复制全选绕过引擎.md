# 外接键盘 Cmd+C / Cmd+A 绕过引擎取文与选区

- 状态：待办
- 记录日期：2026-09-25

## 现状

PLAN §6.1「M2a 选区决定」规定选区与取文的权威在引擎，但 fork 的默认快捷键仍然生效：
`Cmd+C` 走 fork 的 `CopySelectionTextIntent`，在 Dart 侧用 `terminal.buffer.getText(selection)`
自行拼行取文；`Cmd+A` 走 `SelectAllTextIntent`，在 Dart 侧建本地选区，引擎并不知道。
这两条路径的结果可能与菜单「复制」（`CopyRequest` → 引擎 `selected_text`）不一致。

## 下一步

页面给 `TerminalView` 显式传 shortcuts，并用 Actions 覆盖这两个 Intent：复制 → `CopyRequest`，
全选 → 按当前帧首末 `stable_row` 发 `SelectionRequest`。
