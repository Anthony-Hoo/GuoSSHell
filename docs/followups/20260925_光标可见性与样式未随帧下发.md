# 光标可见性与样式未随帧下发

- 状态：待办
- 记录日期：2026-09-25

## 现状

`native/hub/src/session.rs` 的 `send_frame` 只取光标位置，忽略上游 `RenderCursor` 的
`visible` 与 `shape`；Dart 侧固定画块状光标。远端隐藏光标时（多数全屏 TUI）仍会画出光标，
远端切换光标形状（DECSCUSR，例如 vim 插入模式的竖线）也不生效。

## 下一步

`FrameUpdate` 增加光标可见性与形状（或者不可见时把位置置为「无光标」），
`FrameTerminal` 映射到 fork 的光标样式。
