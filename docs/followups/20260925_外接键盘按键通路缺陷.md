# 外接键盘按键通路缺陷（大小写、数字、F 键、输入法）

- 状态：待办（代码推演，未实机复现）
- 记录日期：2026-09-25

## 现状

fork 把硬件按键经 `keyToTerminalKey` 交给 `FrameTerminal.keyInput`；被认领的按键不再进入
文本 / 输入法通路。当前 `keyInput` 对能映射出键名的键一律认领：

- 字母键无论有无修饰都被认领成 `character:x`，而引擎在未协商 CSI-u 时忽略 Shift
  → 外接键盘打不出大写字母
- 数字键换算有误：fork 枚举顺序是 `digit1`…`digit9`、`digit0`，当前区间只命中
  `digit9` / `digit0`，且 `digit9` 被换算成 `1`
- 字母被认领后，外接键盘无法经系统输入法组字（拼音等）
- F1–F12：Dart 发 `f:N`，`native/hub/src/session.rs` 的 `parse_key_code` 只认 `fN`，
  解析失败后按键被静默丢弃

软键盘走文本通路，不受影响。

## 下一步

`keyInput` 对不带 Ctrl / Alt 的可打印键返回 false（交给文本通路），带修饰时才认领；
修正数字换算；统一 F 键名；补键名跨边界的契约测试。外接键盘回归大小写、数字、F 键、拼音。
