# 宽字符行丢字、错位

- 状态：待办（影响 M1/M2 已验收的 CJK 显示；也是 M2a 选区、复制、鼠标命中的列基准）
- 记录日期：2026-09-25

## 现状

上游 `convert_row` 跳过宽字符的占位格，`RenderRow.cells` 是「每字一格、`width` 标宽」。
`native/hub/src/frame_codec.rs` 的 `pack_runs` 用格下标作 `start`、逐格 `len += 1`，
写出的是**格数**，不是注释所说的**列数**；Dart 帧适配器（`frame_terminal.dart` 的
`_buildLine`）按列展开、到 `start + len` 截断。结果：

- 同一 run 内含宽字符时，run 尾部的字被截掉：同色的 `ab中文cd` 画成 `ab中cd`，
  `ls 你好世界.txt` 丢掉 `.txt`
- 宽字符之后的 run 整体左移，与前文重叠
- 选区高亮（Dart 的列）、复制取文（引擎的列）、鼠标上报的列三者对不上

## 下一步

`pack_runs` 按 `cell.width` 累加列号、`len` 按列计；零宽码点与宽度以 Rust 为准
（随帧下发，或按宽度切 run），Dart 不再用自带宽度表推算。Rust、Dart 两侧补
「CJK 后接异色 run」「满行 CJK」「emoji / 组合记号」回归用例。
