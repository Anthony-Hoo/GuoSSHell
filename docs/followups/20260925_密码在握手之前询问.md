# 没存密码时，密码在握手之前询问

- 状态：待办（非阻塞）
- 记录日期：2026-09-25

## 现状

上游的 `AuthPlan::Password` 需要在建立传输之前就带着密码，原生传输再一次性完成 TCP、
握手、主机密钥校验与认证。所以没存密码的连接，App 只能先弹密码框、再连接：

- 首次连接要先输密码、后确认主机密钥（常见客户端的顺序相反）；
- 目标不可达时，用户输完密码才看到网络错误。

上游协议里已有 `InteractionRequest::Password`，但传输从不发出。

## 下一步

改上游（fork 补丁）：`AuthPlan` 允许密码认证不带密码，原生传输在主机密钥校验之后、认证之前
经 `InteractionBroker` 发 `Password` 提问。App 侧把现有的密码框改为响应这条提问。
