# 挂住 Ctrl 后输入不可编码字符会断开会话

- 状态：待办
- 记录日期：2026-09-25

## 现状

键位条挂住 Ctrl 后输入单个字符，`FrameTerminal.textInput` 把它升级成带 control 的
`character:x` 按键事件。上游编码器只给字母、`@`、`[`、`\`、`]`、`^`、`_`、`?`、空格
定义了控制字符，其余字符（数字、多数标点、中文等）返回 `EngineError::UnsupportedInput`；
`native/hub/src/session.rs` 对 `encode_input` 的任何错误都发 `Failed` 并结束会话循环。
一次误触就会断开 SSH 会话。

## 下一步

hub 把 `UnsupportedInput` 当作「丢弃这次输入」（调试输出即可），不终止会话；
Dart 侧只在能映射成控制字符时才升级成按键事件，否则按原文本发送。补单测。
