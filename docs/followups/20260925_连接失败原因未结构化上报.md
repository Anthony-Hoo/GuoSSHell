# 连接失败原因未结构化上报

- 状态：待办（M0 验收「明确的 SessionFailure 分类」目前只在文字层面满足）
- 记录日期：2026-09-25

## 现状

`SessionStatus` 只有 `state` 与自由文本 `detail`。失败类别以 Debug 文本拼进 `detail`，
连接失败时还混着诊断探针的输出。Dart 无法按类别给提示或恢复动作，而 M0-c 的
「超时 → 可能未授权本地网络 → 引导去设置」、M3 的主机密钥变更警告都依赖这一点。

## 下一步

`SessionStatus` 增加失败类别字段，由上游 `TransportError::failure()` / `SessionFailure` 映射
（含 `HostKeyChanged`、`HostKeyRejected`、`Authentication`、`Network`、`Timeout` 等），
Dart 按类别出文案，`detail` 只作调试信息。与移除诊断探针一并处理。
